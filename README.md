# 安评检查助手 - 网络安全

> 基于AI技能框架开发的网络安全评价辅助工具，将专家现场发现的问题自动匹配到评价细则条款、计算扣分、判定风险等级，并一键生成标准化评价报告。

---

## 一、这是干什么

在安全性评价（安评）工作中，专家需要把现场发现的每一个问题，手工对照《安全性评价与生产管理评价细则》逐条找条款、算扣分、定风险等级，再汇总成报告。这项工作**重复、易漏、耗时长**。

本技能把这套流程自动化：

- 你只需用自然语言描述问题（支持批量）
- 技能自动拆分复合问题 → 语义匹配细则条款 → 计算扣分 → 判定风险等级
- 按标准模板生成结构化 Markdown 报告，并自动做一致性校验

**效果：** 单次评价报告的整理时间从数小时级降到分钟级，扣分值、风险等级、引用标准全部可追溯、可复核。

---

## 二、核心功能

| 功能 | 说明 |
|------|------|
| **智能诊断** | 自动将问题描述匹配到对应细则条款，计算扣分并判定风险等级 |
| **隐患排查** | 支持批量问题输入，快速识别高风险项并排序 |
| **标准化报告** | 按统一模板生成 Markdown 报告，含模块得分、问题详情、整改建议、总体评价 |
| **自动校验** | 报告生成后强制运行 `auto_verify.py`，做 6 项一致性检查，不通过不得交付 |
| **知识库持久化** | 评价细则独立存储为 `assets/knowledge_base.json`，支持版本管理与更新 |

**适用场景：** 安全合规检查、风险评估、隐患排查、安评迎检材料准备等专业场景。

## 五、使用流程

1. **加载知识库**：技能自动加载 `assets/knowledge_base.json`，无需每次导入。
2. **输入问题**：用自然语言描述现场发现的问题，支持逐条或批量输入。

   > 示例：
   > 安全设备台账内容不全，缺少安装位置和接入日期，没有制定备份及恢复策略，防火墙存在冗余策略

3. **智能匹配与扣分**：技能自动拆分复合问题、检索最相关条款、计算扣分、判定风险等级。
4. **生成报告**：按模板输出结构化 Markdown 报告，保存到 `reports/` 目录（文件名：`评价报告_yyyyMMdd_HHmmss.md`）。
5. **自动校验（必执行）**：报告生成后立即运行校验脚本，不通过需修正后重新校验。

   ```bash
   python scripts/auto_verify.py <报告文件路径> --output reports/校验报告_<同时间戳>.md
   ```

   - 退出码 `0`：全部通过，正常交付
   - 退出码 `1`：存在偏差，按提示修正后重跑
   - 退出码 `2`：参数错误

## 六、风险等级判定规则

| 判定条件 | 风险等级 |
|----------|----------|
| 扣分 = 标准分（"不得分"） | 高 |
| 问题描述命中高风险关键词（未设置 / 缺失 / 严重 / 失效 / 未建立 / 未开展 / 不得分） | 高 |
| 扣分占标准分比例 ≥ 50% | 中 |
| 扣分占标准分比例 < 50% | 低 |

对应整改时限：高风险立即整改（24 小时内），中风险限期整改（7 个工作日内），低风险持续改进（30 个工作日内）。

当前内置知识库版本 **v2.0**，依据《安全性评价与生产管理评价细则-燃气发电篇 V1.0-信息网络安全 0814 修编版》整理：

- 条款总数：**62 条**
- 总分值：**650 分**
- 覆盖模块：公共规范（170）、机房安全（90）、网络设备（80）、安全设备（100）、服务器（50）、数据安全（50）、应用系统（50）、办公终端（60）

如需适配其他版本细则，直接编辑 `assets/knowledge_base.json` 即可，无需改动脚本逻辑。

## 八、一致性保障机制

为避免 AI 自动生成报告出现扣分值漂移、风险等级错判等问题，技能内置三层保障：

1. **模板约束**：扣分理由与整改建议必须从措辞库中选择，禁止自由创作。
2. **生成即校验**：每次生成报告必须运行 `auto_verify.py` 做 6 项一致性检查。
3. **稳定性抽检**：可运行 `consistency_test.py`（10 次迭代）验证输出稳定性，或运行 `diff_detector.py` 比对两份报告差异。
