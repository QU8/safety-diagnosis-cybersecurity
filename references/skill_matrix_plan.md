# 安评检查助手 - 技能矩阵规划

## 产品定位

**安评检查助手**是一个面向发电厂安全评价的专业技能矩阵，通过标准化知识库、智能诊断引擎和一致性保障机制，为专家检查、运维管理和隐患排查提供高效、专业的技术支持。

## 已完成技能

### 安评检查助手 - 网络安全 ✅

**技能标识**：`safety-diagnosis-cybersecurity`

**核心能力**：
- 智能诊断：基于84条网络安全细则，自动匹配条款并计算扣分
- 隐患排查：支持批量问题输入，快速识别高风险项
- 标准化报告：6章节固定结构，7种扣分理由模板，3种整改建议模板
- 一致性保障：≥95%相似度，支持10次迭代验证

**适用场景**：
- 专家现场检查：网络设备、安全设备、服务器、终端设备等
- 运维日常管理：日常巡检、配置审计、日志分析
- 隐患专项排查：等保合规检查、安全基线检查、漏洞评估

**知识库覆盖**：
- 2.7.1 公共规范（130分）
- 2.7.2 机房安全（100分）
- 2.7.3 网络设备（80分）
- 2.7.4 安全设备（90分）
- 2.7.5 服务器（50分）
- 2.7.6 数据安全管理（40分）
- 2.7.7 应用系统（50分）
- 2.7.8 终端办公设备（60分）

**技术特性**：
- 模板化报告生成（Markdown格式）
- 标准化措辞库（扣分理由、评价结论、整改建议）
- 风险等级自动判定（高/中/低）
- 术语标准化处理
- 一致性测试工具（consistency_test.py）
- 差异检测工具（diff_detector.py）

## 共性技术架构

### 1. 标准化模板体系

所有技能将共享以下模板：

- **报告模板**：6章节固定结构（基本信息、评价概览、问题详情、扣分统计、整改建议、评价结论）
- **措辞库**：7种扣分理由模板、4种评价结论模板、3种整改建议模板
- **风险标准**：高/中/低三档风险等级判定

### 2. 一致性保障机制

所有技能将支持：

- 模板强制加载
- 措辞标准化
- 风险等级自动判定
- 术语标准化处理
- 一致性测试工具

### 3. 知识库管理

- 统一的JSON格式
- 版本管理机制
- 导入导出功能
- 在线编辑支持

### 4. 测试工具集成

- 一致性测试工具（consistency_test.py）
- 差异检测工具（diff_detector.py）
- 自动化测试脚本

## 质量保障体系

### 1. 开发规范

- 所有技能必须遵循"安评检查助手"技术规范
- 代码风格统一（PEP 8）
- 文档格式统一（Markdown）

### 2. 测试标准

- 一致性测试：≥95%相似度
- 准确性测试：条款匹配准确率≥90%
- 性能测试：单次诊断时间≤5秒
- 稳定性测试：10次迭代零错误

### 3. 上线标准

- 通过一致性测试
- 通过准确性测试
- 文档完整且正确
- 知识库数据完整

## 附录：快速创建新技能

### 创建新技能步骤

```bash
# 1. 复制网络安全技能作为模板
cp -r smart-rule-matcher smart-rule-matcher-electrical

# 2. 重命名技能目录
mv smart-rule-matcher-electrical smart-rule-matcher-电气安全

# 3. 修改SKILL.md
# - 修改name字段（技能标识）
# - 修改description字段（技能描述）
# - 修改技能标题（如：安评检查助手 - 电气安全）
# - 修改知识库路径（如：assets/knowledge_base_electrical.json）

# 4. 构建新知识库
# - 收集电气安全评价细则
# - 按照knowledge_base.json格式整理
# - 保存到assets/knowledge_base_electrical.json

# 5. 调整措辞库（如需要）
# - 根据电气安全特点调整扣分理由模板
# - 保存到references/phrasing_templates_electrical.json

# 6. 测试验证
# - 运行一致性测试
# - 运行准确性测试
# - 用户验收测试
```

- [ ] 测试工具已集成（一致性测试、差异检测）
