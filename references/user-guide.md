# 安评检查助手使用说明

## 技能概述
基于导入的评价细则知识库，自动将专家描述的问题匹配到对应细则条款，计算扣分并生成结构化评价报告。支持知识库持久化存储和Markdown格式报告导出。

## 知识库版本信息
- **版本：** 2.0
- **条款总数：** 62条
- **总分值：** 650分
- **来源：** 《安全性评价与生产管理评价细则-燃气发电篇V1.0-信息网络安全0814修编版》
- **更新日期：** 2026年08月15日
- **存储路径：** `assets/knowledge_base.json`

## 知识库特点
1. **完整覆盖：** 包含2.7.1至2.7.8的所有细则条款
2. **分值准确：** 总分值严格控制为650分
3. **结构清晰：** 采用分层结构，支持多级条款关联查询
4. **内容详细：** 每条条款包含详细的扣分规则和依据
5. **格式规范：** 符合JSON标准格式，易于解析和使用
6. **持久存储：** 知识库独立存储，支持版本管理和更新

## 使用流程

### 1. 知识库加载
- 系统自动加载存储的知识库文件
- 无需每次重新导入评价细则

### 2. 问题输入
- 支持批量输入或逐条录入问题描述
- 例如："安全设备台账不符，缺少位置和接入日期，没有制定备份及恢复策略"

### 3. 智能匹配与扣分
- 系统自动拆分复合问题为独立子问题
- 在知识库中检索最相关的条款
- 计算扣分值并生成匹配结果

### 4. 报告生成
- 按预设模板输出结构化报告
- 支持Markdown格式导出
- 报告自动保存到reports目录

### 5. 查看报告
- 打开reports目录查看生成的Markdown报告
- 报告包含完整的匹配结果和扣分计算

## 报告导出设置
- **保存路径：** 当前工作目录\reports\
- **文件名格式：** `评价报告_yyyyMMdd_HHmmss.md`
- **包含内容：** 完整的评价报告，支持Markdown表格和格式化
- **导出状态：** 生成后显示详细的保存路径

## 示例使用

### 输入示例
```
安全设备台账不符，缺少位置和接入日期，没有制定备份及恢复策略，燃气泄漏检测系统未正常运行
```

### 输出结果
- 自动拆分为4个子问题
- 匹配到对应的细则条款
- 计算扣分值
- 生成完整的Markdown格式报告

## 注意事项
1. 确保知识库文件存在且格式正确
2. 问题描述应清晰明确，便于系统准确匹配
3. 如需更新知识库，直接编辑knowledge_base.json文件
4. 报告将自动保存到reports目录，确保该目录存在

## 故障排除
- **知识库加载失败：** 检查knowledge_base.json文件是否存在且格式正确
- **报告导出失败：** 检查reports目录是否存在且有写入权限
- **匹配结果不准确：** 检查问题描述是否清晰，或更新知识库内容
